      設定（せってい） Settings

      The hanger whose condition changed is cycle 1. Same rule as the P5P2 app: tin timer stop at cycle 4, selector stop at cycle 3.

      使（つか）い方（かた） How to use
      1. Choose the condition of the hanger you are loading. Set the 通し番号 to the line's number once (type it, or use − / ＋); it goes up by 1 on every tap.
      2. Choose what is on the set (製品 / テスト板 / ダミー板 / 空ハンガー) and, for 製品, the 本数 (boards on front + rear). Each time you register a hanger set, tap 登録した ＋1. The daily table counts it.
      3. When the condition changes (9分 / 6分 / 5分, P5⇄P2) the page counts down. At the stop cycle the screen turns red, beeps and vibrates until you tap 確認 OK.

      Tap "Test sound" once after opening the page, so the phone allows sound. Keep the volume up. Ask your 班長 before using a phone on the line.
